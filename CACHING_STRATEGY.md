## 1. Multi-Tier Caching Architecture

```
User Request
     │
     ▼
[ Browser Cache ] ── Hit? ──► Instant Render (<10ms)
     │ Miss
     ▼
[ Edge CDN / Vercel Global Network ] ── Hit? ──► Low Latency Edge Response (<50ms)
     │ Miss
     ▼
[ Origin / Static Pre-Rendered Storage ] ──► Compute / Fetch & Cache
```

The caching strategy implements a multi-tier hierarchy optimizing for:
1. **Sub-second Initial Page Load** across mobile and desktop connections.
2. **Instant Repeat Navigation** without network round-trips for static code chunks.
3. **Guaranteed Freshness** for HTML documents so code updates are never stalled behind stale browser caches.

## 2. Tier Details & Header Configuration

### 2.1 Static Fingerprinted Assets (`/assets/*`)
- **Pattern**: `/assets/(.*)` (Generated by Vite with SHA-based content hashes, e.g. `index-CTeDeSqN.js`, `index-BC46hAbG.css`, `About-nmgbQSaJ.js`).
- **Header**: `Cache-Control: public, max-age=31536000, immutable`
- **Behavior**: Because the filename changes whenever the code changes, browsers and edge caches store these assets for 1 full year without revalidating. This guarantees zero 304 roundtrips for returning visitors.

### 2.2 Public Media & Images (`/img/*`, `/videos/*`)
- **Pattern**: `/(img|videos)/(.*)`
- **Header**: `Cache-Control: public, max-age=86400, stale-while-revalidate=604800`
- **Behavior**: Images and video files are cached for 24 hours (`86400` seconds). During the subsequent 7 days (`604800` seconds), stale versions are served instantly while the CDN revalidates in the background.

### 2.3 HTML Documents (`/` and prerendered `/page/index.html`)
- **Pattern**: `dist/*.html`
- **Header**: `Cache-Control: public, max-age=0, must-revalidate` (Vercel default for HTML)
- **Behavior**: Ensures search engine crawlers and users always receive the latest HTML document, which references the newly hashed JS/CSS assets.

### 2.4 Client-Side Preference & Calculation Caching
- **Implementation**: `src/lib/prefs.tsx`
- **Storage**: `localStorage` (`vg_theme`, `vg_lang`)
- **Scope**: User aesthetic theme (day/night) and selected language preference (en, kn, hi, te, ta, ml, mr) are preserved locally across sessions without sending cookies to the server.

## 3. Invalidation & Cache-Busting Mechanics

1. **Deploy Invalidation**: Every production deployment on Vercel automatically purges the CDN cache tags associated with the project alias (`vg-five-self.vercel.app`).
2. **Deterministic Fingerprints**: Vite generates content-based chunk hashes. If a page or component is modified, only that specific chunk gets a new URL; unchanged dependencies continue serving from browser caches.
3. **No Cross-User Leakage**: All cached assets are strictly public and impersonal. No user-specific data or session tokens are stored in shared edge caches.
